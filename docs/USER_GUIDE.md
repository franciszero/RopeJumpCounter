# 用户指南

## 🎯 快速开始

### 第一次使用

1. **安装应用** (参考 [INSTALL.md](../INSTALL.md))
2. **连接摄像头**
3. **运行应用**:
   ```bash
   python main.py
   ```

### 基本操作

- **开始计数**: 应用启动后自动开始
- **暂停/继续**: 按空格键
- **退出**: 按 'q' 键或关闭窗口

## 📱 界面说明

### 主界面元素

- **视频窗口**: 显示实时摄像头画面
- **跳数显示**: 左上角显示当前跳绳次数
- **概率显示**: 左下角显示检测概率
- **性能信息**: 右上角显示 FPS 和延迟
- **状态指示**: 检测到跳跃时红色高亮

### 状态说明

- **RISING**: 检测到上升动作
- **概率值**: 0.0-1.0，越高表示越可能是跳跃
- **FPS**: 每秒处理帧数
- **延迟**: 处理延迟（毫秒）

## ⚙️ 配置选项

### 基本配置

编辑 `config.yaml` 文件：

```yaml
camera:
  width: 640      # 推荐: 640x480 或 1280x720
  height: 480
  fps: 30         # 推荐: 30fps
  device_index: 0 # 如果有多个摄像头，尝试 1, 2...

model:
  threshold: 0.5  # 调整检测敏感度 (0.3-0.7)
```

### 高级配置

```yaml
gpu:
  enabled: true         # 启用 GPU 加速
  mixed_precision: true # 提升性能

performance:
  max_fps: 30          # 限制最大帧率
  
ui:
  show_debug_info: true # 显示详细信息
```

## 🎮 使用技巧

### 获得最佳效果

1. **光线条件**:
   - 确保充足的光线
   - 避免背光和强烈阴影
   - 均匀的背景光照

2. **摄像头位置**:
   - 距离 1.5-2 米
   - 高度与胸部平齐
   - 确保全身在画面内

3. **跳绳姿势**:
   - 保持标准跳绳姿势
   - 避免过度摆动
   - 保持在摄像头视野内

### 调整检测敏感度

如果计数不准确：

- **漏计数**: 降低 threshold (如 0.3-0.4)
- **误计数**: 提高 threshold (如 0.6-0.7)

### 性能优化

1. **降低分辨率**: 640x480 通常足够
2. **启用 GPU**: 如果有 NVIDIA 显卡
3. **关闭其他程序**: 释放 CPU/GPU 资源

## 🔧 故障排除

### 常见问题

#### 摄像头无法打开
```
解决方案:
1. 检查摄像头连接
2. 尝试不同的 device_index (0, 1, 2...)
3. 关闭其他使用摄像头的程序
4. 检查摄像头权限
```

#### 检测不准确
```
解决方案:
1. 调整 threshold 值
2. 改善光线条件
3. 调整摄像头位置
4. 检查跳绳姿势
```

#### 性能问题 (低 FPS)
```
解决方案:
1. 降低视频分辨率
2. 启用 GPU 加速
3. 关闭不必要的程序
4. 检查系统资源使用
```

#### 应用崩溃
```
解决方案:
1. 检查错误日志 (logs/ 目录)
2. 确认依赖安装正确
3. 尝试重新安装
4. 报告 bug (包含错误信息)
```

## 📊 数据管理

### 视频录制

启用视频录制：
```yaml
save_video_path: "data/recordings"
```

录制的视频将保存为：
- 格式: AVI (XVID 编码)
- 命名: `jump_YYYY.MM.DD.HH.MM.SS.avi`

### 日志文件

日志文件位置: `logs/`
- 包含详细的运行信息
- 用于问题诊断
- 可配置日志级别

## 🎯 高级功能

### 多模式运行

```bash
# 实时计数 (默认)
python main.py

# 旧版本模式
python run.py legacy

# 可视化模式
python run.py visualize --model your_model.keras --video test.mp4
```

### 自定义模型

1. 将模型文件放入 `model_files/` 目录
2. 更新配置文件中的 `model_name`
3. 重启应用

### 批量处理

```bash
# 处理视频文件
python run.py visualize --video path/to/video.mp4
```

## 📈 性能监控

### 实时指标

- **FPS**: 处理帧率，建议 >20
- **延迟**: 处理延迟，建议 <50ms
- **准确率**: 通过实际对比验证

### 优化建议

1. **硬件升级**: 更好的 CPU/GPU
2. **参数调优**: 调整模型参数
3. **环境优化**: 改善拍摄环境
